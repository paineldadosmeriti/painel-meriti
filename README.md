# painel-meriti
Um painel para quem busca renda formal, sindicatos e entidades de classe, e trabalhadores informais de São João de Meriti que buscam orientação de planejamento — com dados oficiais sobre desigualdade de resultados, discriminação no mercado de trabalho e os caminhos práticos para reduzi-la. Continuação do diagnóstico produzido no PIEX I.
